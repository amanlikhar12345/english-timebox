# English Timebox

A Python-based English learning application designed to help users improve their English skills through structured, time-boxed daily practice.

## 🚀 Features

- 📖 Reading Practice
- 🗣️ Speaking Practice
- ✍️ Writing Practice
- 📚 Vocabulary Building
- 🔤 Grammar Practice
- ⏱️ Time-boxed Learning Sessions
- 📊 Performance Tracking
- 🎯 Daily English Practice

## 🛠️ Technologies Used

- Python
- Tkinter
- MySQL
- HTML
- CSS
- JavaScript
